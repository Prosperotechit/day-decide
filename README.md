# Day Decide

Small tools that take the overthinking out of everyday choices.

## Tools

- **Outfit Match** — pick an occasion and the weather, and it ranks outfit combinations from your wardrobe by color harmony, formality fit, and pattern clash.
- **Room Layout** — describe a room's dimensions, door, and window, and it suggests a furniture arrangement that keeps the door clear and the light open, with a diagram and reasoning.

Wardrobe data is stored in the browser (`localStorage`); there's no backend.

## Development

```sh
npm install
npm run dev
```

Built with Vite, React, TypeScript, and Tailwind CSS.
